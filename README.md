# Ankit Immersive Studio — Kage Landing Page

This project uses the published `@designcodeio/threeui` `KageLandingPage` component with the requested typography and color props.

- `npm install` installs the React/Vite app and ThreeUI.
- `npm run dev` starts local development.
- `npm run build` copies the canonical Kage HTML and its authored assets from the installed package into `public/landing-pages`, then builds the app.
- The previous standalone studio page is preserved at `legacy/index.html`.

The authored Kage document is copied without editing. Its local relative asset paths are preserved so its Three.js scenes, typography, and responsive interactions can load normally.
